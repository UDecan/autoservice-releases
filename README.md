# Автосервис самообслуживания — релизы

Здесь публикуются установщики программы «Автосервис самообслуживания — учёт аренды».
Исходный код — в закрытом репозитории; файлы сюда выкладывает GitHub Actions по тегу `v<версия>`.

- `Autoservice-<версия>-setup.exe` — установщик (рекомендуется), ставится поверх прежней версии, данные сохраняются.
- `Autoservice-<версия>-win-x64.exe` — переносная версия без установки.
- `*.sha256` — контрольные суммы.

Программа сама проверяет последний релиз этого репозитория и предлагает обновиться (раздел «О программе»).
